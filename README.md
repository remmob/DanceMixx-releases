# DanceMixx

De muziekspeler voor de dansschool: twee decks met automatisch doorspelen, de muziekbibliotheek met dansen en MPM,
afspeellijsten, historie en jingles.

## Aan de slag in 5 stappen

### 1. Downloaden
Klik rechts op **Releases** (of [hier](https://github.com/remmob/DanceMixx-releases/releases/latest)) en download
**DanceMixx.exe** bij de nieuwste versie.

Zet het bestand in een eigen map, bijvoorbeeld `Documenten\DanceMixx` of een map op je bureaublad.
*Niet* in `Program Files`: dan kan DanceMixx zichzelf niet bijwerken.

Je hoeft niets te installeren. Werkt op Windows 10 en 11 (64-bit).

### 2. De eerste keer starten
Dubbelklik op **DanceMixx.exe**. Windows laat misschien de melding *"Windows heeft uw pc beschermd"* zien.
Klik dan op **Meer info** en daarna op **Toch uitvoeren**. Dat hoeft maar één keer.

### 3. De muziekbibliotheek ophalen
Je hebt van Mischa een **toegangscode** gekregen, bijvoorbeeld `DMX-7K3Q-9TWP-4HXR`.

1. Klik bovenin op **Instellingen**.
2. Vul bij **Muziekbibliotheek** je code in bij *Toegangscode gedeelde bibliotheek*.
3. Klik op **Opslaan**.
4. Bovenin verschijnt een blauwe melding **Nieuwe muziekbibliotheek · bijwerken**. Klik erop.

### 4. Je muziekmappen instellen
De bibliotheek weet welke muziek er is, maar niet waar die op jouw computer staat.

1. Open opnieuw **Instellingen** → **Muziekbibliotheek**.
2. Je ziet de hoofdmappen uit de bibliotheek, bijvoorbeeld `M:\Muziek`.
3. Klik bij elke map die je hebt op **Kiezen...** en kies de map waar die muziek bij jou staat.
   DanceMixx telt direct hoeveel bestanden er gevonden worden.
4. Klik op **Opslaan**.

Tracks die rood zijn in het tabblad **Database**, zijn op jouw computer niet gevonden.

### 5. Muziek draaien
- Zoek een track in het tabblad **Database** (zoeken op titel, artiest of CD, of kies een dans).
- **Sleep** de track naar Deck A of Deck B, of klik met de rechtermuisknop → **Laden in Deck A**.
- Druk op **PLAY**.
- Zet beide decks op **AUTO**: dan start het andere deck vanzelf als een track afgelopen is.
- Met **AP** (auto pause) staat de volgende track klaar op pauze: jij bepaalt wanneer hij start. Handig bij les.

Druk in DanceMixx op **F1** voor de complete handleiding met plaatjes.

## Updates
Is er een nieuwe versie van DanceMixx of een nieuwe muziekbibliotheek, dan zie je bij het opstarten bovenin een
blauwe melding. Klik erop om bij te werken. Je instellingen, afspeellijsten, historie en je eigen aanpassingen
blijven gewoon staan. Tijdens het draaien wordt er nooit iets bijgewerkt.

## Problemen?
- **Geen geluid** (rode balk bovenin): DanceMixx probeert het elke paar seconden opnieuw. Werkt ander geluid op
  je computer ook niet, herstart dan de computer.
- **"Je toegangscode geeft geen toegang"**: controleer de code, of vraag Mischa om een nieuwe.
- Andere vragen: neem contact op met Mischa.
